# CT Scanner Simulator 3D

Protótipo educacional em React, TypeScript e Three.js, com gantry 3D, mesa móvel, laser, rotação demonstrativa, controles de parâmetros, aquisição fictícia e visualizador de cortes sintéticos.

## Executar
Requer Node.js 20+:

```bash
npm install
npm run dev
```

## Limites e segurança
Este projeto não é um produto oficial da GE HealthCare, não reproduz software proprietário, não controla hardware médico e não é adequado para diagnóstico ou treinamento operacional real. Valores, protocolos e imagens são ilustrativos. Não modela física de raios X, dose, reconstrução clínica validada ou DICOM clínico.
